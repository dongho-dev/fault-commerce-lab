CS-11·12는 실제 HTTP 요청과 DB 판정에 근거한다. 해당 두 사례에 대한 브라우저 화면 검증으로 확대 해석하지 않는다. CS-13은 같은 검증과 격리된 Linux 브라우저에서의 화면 확인을 수행했다. 새 임시 DB에서 정상 소스로 되돌린 대조 검증이며, 과거 장애 데이터의 복구를 뜻하지 않는다.

CS-11·12는 각각 새 환경에서 정상·증상 재현·원복을 3회씩 통과했다. 두 사례 합계 18개 단계다. CS-13은 한 번의 세 단계 검증을 수행했으며 각 단계에서 같은 서비스 변경 절차를 두 번 확인했다. 실행 식별자와 이미지·종료 시각은 기계 판독 기록에 보존했다. 원자료는 제작자의 artifacts/cs-labs 아래 실행별 디렉터리에 보존한다. 원인과 정답을 노출하는 자료는 문제 본문에 포함하지 않는다.

[기계 판독 기록](advanced-verification.json) · [실행 안내](../../lab_suite/README.md)

CS-14는 새 환경에서 세 단계 전체를 3회 확인했다. 오류 재현은 실제 HTTP 요청과 DB 판정에 근거하며, Linux 브라우저에서는 정상 상품 표시 경로를 확인했다. 오류 순간의 브라우저 화면을 관측한 것으로 확대 해석하지 않는다.

CS-15는 정상·증상 재현·원복의 세 단계를 실제 HTTP 요청, DB 판정과 격리된 Linux 브라우저로 확인했다. 기존 창과 새 창의 상품 표시를 비교했고, 새 상품을 두 번 순서대로 등록한 뒤 같은 관찰을 확인했다. 원복 소스는 정상 소스와 동일하며, 보호 대상도 유지했다.

CS-16 이후 실습도 동일한 정상·증상 재현·원복 절차로 확인한다. 공통 검증 범위는 실제 HTTP 요청과 독립 DB 판정이며, 브라우저 동작까지 검증했다는 의미는 아니다. 문제별 실행 식별자와 검증 시각은 기계 판독 기록을 따른다. 난이도 대응표는 공개 자료에 포함하지 않는다.
