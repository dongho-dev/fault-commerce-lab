## 상태 읽는 법

- **준비 확인:** 출제 환경에서 정상·의도한 증상 재현·정상 소스 원복을 확인한 상태다. 학습자의 해결 완료와 별도다.
- **이슈 상태:** 실제 GitHub의 열림·닫힘 상태다. 삭제된 과거 이슈를 현재 문제 목록으로 다시 등록하지 않는다.
- **개선 기록:** 문제를 해결한 후 해당 이슈에 수정·검증 기록을 연결한다. 이 표의 준비 확인을 개인의 해결 실적으로 집계하지 않는다.
- 새 문제는 gpt-6-astra/xhigh 서브에이전트가 출제하고 Codex가 실행 검증했다.
