03 · BUILT FOR INVESTIGATION

감이 아니라,
관측된 사실로.

화면의 모든 요청은 request ID, 구조화 로그, Prometheus 지표로 이어집니다. 독립 Oracle은 애플리케이션을 거치지 않고 최종 DB 상태를 심판합니다.

01

Atomic stock

조건부 PostgreSQL UPDATE가 충분한 재고에만 성공합니다. Python 전역 잠금은 없습니다.

current_stock ≥ quantity
02

Trace every request

응답 헤더부터 JSON 로그까지 같은 request ID로 한 거래의 흐름을 연결합니다.

X-Request-ID
03

Independent truth

Oracle이 PostgreSQL에 직접 연결해 재고 방정식과 주문 금액을 별도로 검증합니다.

initial − confirmed = current
